# Decisiones

Registro corto de decisiones de arquitectura. Cada una dice qué se eligió y por qué.

| #   | Decisión                                                             | Por qué                                                                                                                                                                                                 |
| --- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D01 | Monorepo con pnpm workspaces (`apps/api`, `apps/web`)                | Un solo repo; pnpm por seguridad (node_modules estricto, scripts de instalación bloqueados).                                                                                                            |
| D02 | TypeScript estricto, fijado en 6.0.x                                 | `typescript-eslint` todavía exige `typescript <6.1.0`. Los tipos no validan en ejecución: para eso está Zod.                                                                                            |
| D03 | Express                                                              | Elección del equipo; se monta en Netlify Functions con `serverless-http`.                                                                                                                               |
| D04 | `createApp()` separado del adaptador de plataforma                   | Cambiar de hosting implica tocar un solo archivo.                                                                                                                                                       |
| D05 | Hosting en Netlify (plan gratis)                                     | El plan Hobby de Vercel prohíbe el uso comercial; Netlify lo permite. Render se descartó por el arranque en frío (~50 s); Cloudflare Workers por el límite de 10 ms de CPU, insuficiente para Argon2id. |
| D06 | Postgres en Supabase                                                 | Gratis; ojo: el proyecto gratis se pausa tras una semana sin actividad. Conexión por el pooler.                                                                                                         |
| D07 | Drizzle ORM sobre `pg`                                               | Esquema único en TS del que salen tipos, migraciones (`drizzle-kit`) y esquemas Zod (`drizzle-zod`).                                                                                                    |
| D08 | Sesiones en Postgres con cookie httpOnly, Secure, SameSite           | Se pueden revocar al instante, a diferencia de un JWT.                                                                                                                                                  |
| D09 | Argon2id (`@node-rs/argon2`) para contraseñas                        | Primera opción de OWASP. Plan B: `scrypt` de `node:crypto`.                                                                                                                                             |
| D10 | Login con teléfono + contraseña                                      | El nombre no es único. Sin email, Caro restablece contraseñas desde el panel.                                                                                                                           |
| D11 | Astro + React en islas + Tailwind + GSAP                             | Inicio y catálogo como HTML estático (SEO, carga rápida); reserva y panel como islas de React; GSAP para la animación del letrero (aprobado el 2026-11-18).                                             |
| D12 | Notificaciones gratis: links `wa.me` + push web para Caro            | La API oficial de WhatsApp cobra por mensaje iniciado por el negocio; las librerías no oficiales arriesgan el bloqueo del número.                                                                       |
| D13 | Calendario propio en la base de datos                                | Una sola fuente de verdad; sin sincronizar con Google Calendar en v1.                                                                                                                                   |
| D14 | Restricción de exclusión sobre `tstzrange(start_at, occupied_until)` | La base de datos garantiza que no haya citas superpuestas, incluido el margen.                                                                                                                          |
| D15 | Reglas de negocio en la tabla `settings`                             | Caro las ajusta desde el panel sin cambiar código.                                                                                                                                                      |
| D16 | Borrado de cuenta = anonimización                                    | Cumple la Ley 1581 sin perder el historial de ingresos.                                                                                                                                                 |
| D17 | Código en inglés, comentarios y UI en español                        | El equipo es de habla hispana; los identificadores siguen el estándar del ecosistema.                                                                                                                   |
| D18 | Festivos de Colombia calculados en código                            | Fechas fijas, Ley Emiliani y los que dependen de la Pascua salen de una regla: no hay que cargarlos en la base cada año.                                                                                |
| D19 | Identidad visual "Nude editorial", con tema oscuro "Noche de salón"  | Elegancia y prestigio en pasteles (hueso, nude, rosa, champaña); el fucsia queda solo en el letrero. El oscuro sigue al celular y se puede elegir.                                                      |
| D20 | Colores por función en Tailwind (`canvas`, `ink`, `primary`…)        | Los componentes no nombran colores: el tema oscuro solo cambia los valores, sin clases duplicadas.                                                                                                      |
| D21 | Fuentes alojadas con Fontsource: Jost y Cormorant Garamond           | Carga más rápida en 4G y sin mandar a Google los datos de quien visita.                                                                                                                                 |
| D22 | Letrero en SVG (Allura convertida a trazos) animado con GSAP         | Nítido en cualquier pantalla y animable por partes; la animación va solo en la portada y respeta "reducir movimiento".                                                                                  |
